# Stitch Prompts - Save & Borrow

Paste the master brief and tokens first. One prompt per screen; each is self-contained.

## S-CB-060 - Save & Borrow landing

```text
Design the "Save & Borrow landing" screen of the YourApp mobile banking app (390 x 844, light mode), following the master design brief and tokens.
Purpose: Entry to savings and borrowing products.
Layout, top to bottom:
- Header summary (total saved if any)
- Product cards (each independent): Target Savings, Group Savings (Cooperatives, Ajo/Esusu), Pay Am Small, Borrow, Escrow
- Each card: icon, title, one-line benefit, 'Open'
Navigation: Open -> product home (Stage 2).
Also show or consider these states: Products not enabled are hidden by feature flag.
Rules: use a neutral placeholder wordmark 'YourApp' (no real bank logo); naira amounts with tabular numerals; status by icon plus text; 52 px buttons and inputs; keep it calm and uncluttered.
```
