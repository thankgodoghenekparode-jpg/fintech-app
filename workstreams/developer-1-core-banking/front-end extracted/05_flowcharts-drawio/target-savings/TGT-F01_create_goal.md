# TGT-F01 Create and Fund a Goal

From idea to first deposit.

Requirements: TGT-GOL-001..002, TGT-FUN-001..002

## Steps and branches

- **[a] START:** Save & Borrow > Target Savings > New goal -> [b]
- **[b] INPUT/OUTPUT:** Name, target amount, theme -> [c]
- **[c] INPUT/OUTPUT:** Choose deadline or contribution schedule -> [d]
- **[d] STEP:** App computes required contribution -> [e]
- **[e] INPUT/OUTPUT:** Choose mode: Flexible or Locked (penalty shown) -> [f]
- **[f] INPUT/OUTPUT:** Choose funding: auto-save with consent and/or first top-up -> [g]
- **[g] STEP:** PIN -> [h]
- **[h] STEP:** Create pocket; post first deposit -> [i]
- **[i] END:** Goal active
