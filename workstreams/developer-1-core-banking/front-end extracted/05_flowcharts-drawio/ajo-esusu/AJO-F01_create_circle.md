# AJO-F01 Create and Launch a Circle

From creation to live.

Requirements: AJO-SET-001..006, AJO-MEM-002

## Steps and branches

- **[a] START:** Creator taps Create circle -> [b]
- **[b] INPUT/OUTPUT:** Enter name, amount, frequency, slots, start date -> [c]
- **[c] INPUT/OUTPUT:** Choose protection mode and payout order method -> [d]
- **[d] STEP:** Create tenant; provision dedicated account (RESTRICTED) -> [e]
- **[e] STEP:** Share invite link or code -> [f]
- **[f] STEP:** Members join and accept terms; set auto-debit; provide cover if PROTECTED -> [g]
- **[g] DECISION:** All slots filled and ready? -> if no, invite more: [e]; if yes: [h]
- **[h] STEP:** Run order draw or lock chosen order -> [i]
- **[i] STEP:** Activate account; schedule rounds -> [j]
- **[j] END:** Circle ACTIVE
