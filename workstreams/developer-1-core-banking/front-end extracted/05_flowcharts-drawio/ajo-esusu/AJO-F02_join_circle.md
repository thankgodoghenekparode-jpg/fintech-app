# AJO-F02 Join a Circle

Member joins and sets up protection.

Requirements: AJO-MEM-001, AJO-SET-005, AJO-PRO-001..002

## Steps and branches

- **[a] START:** Open invite link or enter code -> [b]
- **[b] STEP:** Show terms, protection mode, amount, schedule, my slot rules -> [c]
- **[c] INPUT/OUTPUT:** Accept terms -> [d]
- **[d] DECISION:** Protection mode -> if protected: [e]; if safeguards only: [g]
- **[e] INPUT/OUTPUT:** Choose cover guarantor or security deposit -> [f]
- **[g] INPUT/OUTPUT:** Enable auto-debit with consent -> [h]
- **[f] STEP:** Guarantor accepts in-app (PIN) / deposit moved to hold -> [g]
- **[h] END:** Member ready
