# COOP-F02 Join Cooperative

Member joins through a code or link.

Requirements: COOP-MEM-001..003

## Steps and branches

- **[a] START:** Customer opens invite link or enters code -> [b]
- **[b] STEP:** Show cooperative summary and rules -> [c]
- **[c] INPUT/OUTPUT:** Submit join request (with message) -> [d]
- **[d] STEP:** Admins notified -> [e]
- **[e] DECISION:** Admin decision -> if approve: [f]; if reject: [g]
- **[f] STEP:** Approved: create member record and number; notify -> [h]
- **[g] STEP:** Rejected: notify with reason -> [i]
- **[h] STEP:** Member sets contribution plan and auto-deduct (optional) -> [i]
- **[i] END:** Member active
