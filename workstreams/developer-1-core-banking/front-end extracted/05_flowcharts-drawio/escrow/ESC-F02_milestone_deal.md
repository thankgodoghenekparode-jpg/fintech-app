# ESC-F02 Service Deal with Milestones

Staged releases.

Requirements: ESC-REL-002, ESC-REL-004

## Steps and branches

- **[a] START:** Deal with milestones agreed and funded -> [b]
- **[b] STEP:** Seller submits milestone with evidence -> [c]
- **[c] DECISION:** Buyer approves within window? -> if approve: [d]; if revise: [e]; if no response: [g]
- **[d] STEP:** Release milestone amount -> [f]
- **[e] STEP:** Revision request -> [b]
- **[g] STEP:** Auto-release after window if proof submitted and no response -> [d]
- **[f] DECISION:** More milestones? -> if yes: [b]; if no: [h]
- **[h] END:** Deal complete
