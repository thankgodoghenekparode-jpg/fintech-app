# INS-F03 Reward Earning and Credit

Eligibility, budget and credit.

Requirements: INS-RWD-001..004

## Steps and branches

- **[a] START:** Qualifying event (for example bill payment) -> [b]
- **[b] STEP:** Evaluate campaign rules -> [c]
- **[c] DECISION:** Eligible and under caps? -> if no: [d]; if yes: [e]
- **[d] STEP:** Skip
- **[e] DECISION:** Reward budget available? -> if no: [f]; if yes: [g]
- **[f] STEP:** Pause campaign; alert admins
- **[g] STEP:** Create reward entry (pending) -> [h]
- **[h] STEP:** Credit reward after confirmation window -> [i]
- **[i] END:** Notify customer
