# Component Sheet Prompts (generate before screens)

## 1. Buttons, inputs, chips
```text
Design a component sheet for the YourApp banking app (light mode, tokens from the brief): primary, secondary, tertiary and destructive buttons (52 px, 12 px radius) in default, pressed, disabled and loading states; text input, phone input with +234, amount input with large tabular numerals, OTP 6-box input, search field; status chips (Pending amber, Successful green, Failed red, Reversed grey-blue) with icon plus text.
```
## 2. Navigation and lists
```text
Design a component sheet: bottom navigation bar with five tabs (Home, Payments, Cards, Save & Borrow, More) with active and unread-badge states; list row; transaction row (icon, counterparty, narration, amount with +/-, time, status chip); section header with action link; tabs and segmented control.
```
## 3. Sheets, dialogs, feedback
```text
Design a component sheet: bottom sheet with drag handle; confirmation sheet with rows To, Bank, Amount, Fee, Total and a primary button; dialog with two actions; info, success, warning and error banners; toast; skeleton loaders for a list and a card; empty state and error state with simple illustration.
```
## 4. PIN pad and security
```text
Design the custom PIN pad: four dots at top, numeric keypad 3x4 with biometric key and delete, error shake state, 'Forgot PIN' link. Calm, high contrast, large keys.
```
## 5. Bank cards
```text
Design six virtual bank card visuals (ratio 1.586:1, 24 px radius, subtle gradient and soft geometric pattern): Berry, Midnight, Coral, Forest, Sand, Slate. Show front with card name, last four digits and network mark placeholder. Also show a frozen state with lock overlay and a skeleton creating state. Original art; do not imitate any real bank card.
```
## 6. Receipt
```text
Design a shareable transaction receipt: placeholder app wordmark, status chip, large amount, rows (To, Bank, From, Narration, Fee, Reference, Date and time), footer buttons 'Share' and 'Report a problem'. Clean and printable.
```
