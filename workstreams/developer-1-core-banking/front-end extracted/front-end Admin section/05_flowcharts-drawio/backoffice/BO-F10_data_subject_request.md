# BO-F10 Data Subject Request

Privacy request handling.

Requirements: BO-023

## Steps and branches

- **[a] START:** Request received (app or email) -> [b]
- **[b] STEP:** Verify identity -> [c]
- **[c] DECISION:** Request type and legal basis -> if fulfil: [d]; if deny: [e]; if extend: [f]
- **[d] STEP:** Collect data from sources; prepare response -> [g]
- **[e] STEP:** Deny or restrict with reason (for example legal retention) -> [g]
- **[f] STEP:** Extend with notice if needed -> [d]
- **[g] STEP:** Respond within the deadline; keep evidence -> [h]
- **[h] END:** Closed
