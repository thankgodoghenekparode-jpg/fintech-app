# BO-F13 Service Notice or Template Change

Customer communication with approval.

Requirements: BO-024

## Steps and branches

- **[a] START:** Staff drafts notice or template version -> [b]
- **[b] STEP:** Preview and test send to staff only -> [c]
- **[c] STEP:** Submit for approval -> [d]
- **[d] DECISION:** Approver decision -> if approve: [e]; if reject: [f]
- **[e] STEP:** Approved: schedule or activate version -> [g]
- **[f] STEP:** Rejected: return with comments -> [a]
- **[g] STEP:** Send; record counts and delivery results -> [h]
- **[h] END:** Audit logged
