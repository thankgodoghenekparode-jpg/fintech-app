# BO-F12 Card Chargeback

Dispute to issuer.

Requirements: BO-022

## Steps and branches

- **[a] START:** Customer reports card transaction problem -> [b]
- **[b] STEP:** Ticket linked; evidence requested -> [c]
- **[c] STEP:** Dispute officer reviews; deadline set -> [d]
- **[d] DECISION:** Valid claim? -> if yes: [e]; if no: [f]
- **[e] STEP:** Submit to issuer; optional provisional credit (dual control) -> [g]
- **[f] STEP:** Close with explanation -> [j]
- **[g] DECISION:** Issuer outcome -> if won: [h]; if lost: [i]
- **[j] END:** Closed
- **[h] STEP:** Won: finalise credit -> [j]
- **[i] STEP:** Lost: reverse provisional credit; inform customer -> [j]
