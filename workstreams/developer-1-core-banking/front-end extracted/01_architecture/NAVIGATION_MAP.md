# Navigation Map (mobile)

Bottom tabs (decided): Home | Payments | Cards | Save & Borrow | More

```
Home
  Balance (hide/show) · Quick actions: Send, Airtime & Bills, Add money, Cards, Savings
  Card carousel · Recent activity (-> Transaction detail -> Receipt / Report a problem)
  Notification bell -> Notification centre
Payments
  Send money (To bank / To saved beneficiary / Request money / QR)
  Airtime & data · Bills · Scheduled payments · Dues & Levies (Stage 2) · Beneficiaries · History
Cards
  Card list/carousel -> Card detail (freeze, limits, details, alerts) · Create card
Save & Borrow
  Target Savings (Stage 2) · Group Savings: Cooperatives, Ajo/Esusu (Stage 2)
  Pay Am Small (Stage 2) · Borrow / Instant Loan (Stage 2) · Escrow (Stage 2)
More
  Profile & KYC · Security · Limits · Statements · Help & Support · Legal · Locator
  Tenant switcher (if user manages a tenant) · Settings · Log out
```

Rules: every common task is 3 taps or fewer from Home; Back always returns to the previous screen; no more than five tabs; products appear as entries, never as new tabs.
