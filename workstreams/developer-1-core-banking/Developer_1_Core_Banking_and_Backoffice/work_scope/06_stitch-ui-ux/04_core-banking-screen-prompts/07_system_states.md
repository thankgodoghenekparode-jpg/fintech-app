## S-CB-090 - Offline

```text
Design the "Offline" screen of the YourApp mobile banking app (390 x 844, light mode), following the master design brief and tokens.
Purpose: Handle no connection.
Layout, top to bottom:
- Banner: You are offline
- Cached data where safe
- Money actions disabled with explanation
Navigation: Retry.
Also show or consider these states: Default.
Rules: use a neutral placeholder wordmark 'YourApp' (no real bank logo); naira amounts with tabular numerals; status by icon plus text; 52 px buttons and inputs; keep it calm and uncluttered.
```
