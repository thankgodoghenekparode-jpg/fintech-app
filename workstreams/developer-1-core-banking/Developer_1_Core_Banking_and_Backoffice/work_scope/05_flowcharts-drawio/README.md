# Flowcharts (front-end)

For every flow there are three files with the same name:
- `.drawio` - open in draw.io (diagrams.net) to view and edit; colours follow the design tokens.
- `.mmd` - the same flow as Mermaid text (for AI agents and Markdown viewers).
- `.md` - the same flow as numbered steps with branches (for AI agents).

Core flows F-01 to F-11 are here. Product flows are added in Stage 2 (instant loan, cooperative, ajo, Pay Am Small, escrow, revenue, target savings, merchant tools, agents, insights). A master map of every flow is generated at the end of Stage 2.

Product flows live in sub-folders named after the product (for example `cooperative/`, `ajo-esusu/`, `target-savings/`). The same files are copied into `back-end/17_flowcharts-drawio/<product>/`.
