# F-08 Report a Problem and Support

Transaction dispute and ticket tracking.

Requirements: CB-SUP-001..005

## Steps and branches

- **[a] START:** Open transaction detail -> [b]
- **[b] STEP:** Tap Report a problem -> [c]
- **[c] INPUT/OUTPUT:** Choose reason; add description and evidence -> [d]
- **[d] STEP:** Create ticket linked to transaction -> [e]
- **[e] STEP:** Show ticket number and response time -> [f]
- **[f] STEP:** Support/dispute officer reviews -> [g]
- **[g] DECISION:** Resolution -> if valid: [h]; if not valid: [i]
- **[h] STEP:** Refund or reversal (dual control) -> [j]
- **[i] STEP:** Explain and close with reason -> [j]
- **[j] STEP:** Notify customer; ticket closed -> [k]
- **[k] END:** Done
