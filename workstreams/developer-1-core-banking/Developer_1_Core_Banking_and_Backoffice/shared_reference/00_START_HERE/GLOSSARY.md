# Glossary
| Term | Meaning |
|---|---|
| Kobo | Minor unit of the naira (100 kobo = 1 naira). All amounts stored as integer kobo. |
| BVN | Bank Verification Number, used for identity verification. |
| NIN | National Identification Number. |
| NIP | Nigeria Inter-Bank Instant Payment system used for interbank transfers. |
| KYC tier | Verification level that sets an account's limits. |
| Ledger | Double-entry record of every money movement. The source of truth for balances. |
| Idempotency key | Unique client-generated key that guarantees a retried request cannot move money twice. |
| Tenant | An independent organisation inside a multi-tenant product (a cooperative, an ajo circle, a vendor store, a collector). |
| Group engine | Shared multi-tenant module powering Cooperative and Ajo/Esusu. |
| Vault | Customer's held balance for a Pay Am Small price-lock plan. |
| Pocket | Ledger sub-balance inside a customer account (for example a Target Savings goal). |
| Holdback | Share of a vendor payout released after delivery confirmation (Pay Am Small). [OPEN] |
| Collector | An organisation collecting dues or levies in the Revenue product. |
| Payer | A person who owes a due or levy to a collector. |
| Back office | Staff-only admin console. |
| Foundation bank | Zenith Bank, the licensed bank holding accounts and funds. |
