# ESC-F03 Dispute Resolution

Freeze, evidence, decision, appeal.

Requirements: ESC-DSP-001..005

## Steps and branches

- **[a] START:** Party opens dispute in window -> [b]
- **[b] STEP:** Freeze funds; notify other party -> [c]
- **[c] STEP:** Both upload evidence by deadline -> [d]
- **[d] STEP:** Dispute officer reviews; may request more info -> [e]
- **[e] DECISION:** Decision -> if release: [f]; if refund: [g]; if split: [h]
- **[f] STEP:** Release to seller -> [i]
- **[g] STEP:** Refund to buyer -> [i]
- **[h] STEP:** Split per decision -> [i]
- **[i] DECISION:** Appeal requested? -> if yes: [j]; if no: [k]
- **[j] STEP:** Second reviewer decides -> [k]
- **[k] STEP:** Apply fees per outcome -> [l]
- **[l] END:** Closed with rationale
